# RayTracerViewでのPBVR逐次プレビュー

## 状態

既存の `RayTracerView` に `PBVR Progressive Preview` パネルと自動実証シナリオを追加した。ユーザー承認後、Releaseビルド、CPU40件・GPU13件のテスト、逐次プレビューの9ステップ、既存startup・command_catalog・camera_controlシナリオが成功した。[実際のビューでの実証結果](../../../reaserch/pbvr_photon_transport/results/2026-10-07/progressive_view/README.md) を参照。独立した32パス参照への間接光差は1パス46.5%から32パス10.0%へ減少した。

## 操作と蓄積

RayTracer Viewパネルの `PBVR Cornell Preview`、またはViewメニューから専用パネルを開き `Start / reset` を押す。専用パネルは組み込みコーネルボックスを表示し、ロード済みglTFのプレビューとは独立する。画像をドラッグするかYaw/Pitch/Distanceを変更するとカメラが変わる。

操作直後は、半球16→8→8、光源位置2点、再放出上限8点、3次、細分化2段で粗い画像を更新する。操作が0.35秒止まり、粗い画像が完成したら、半球64→32→16→16、光源位置8点、上限32点、4次、細分化3段へ切り替える。最終画像は両段階とも96×96、集約半径0.12。

カメラ変更と品質段階の切替で世代番号を進め、平均と分散をリセットする。古い世代の非同期結果は捨てる。計算途中の1パスはキャンセルせず、新しいカメラの仕事を次に開始するため、更新遅延にはその1パスの待ち時間が含まれる。

精細段階では毎パス光源位置と再放出点選択の乱数を変え、線形HDRの間接光をWelford法で平均する。固定した直接光・発光を加えてから表示変換する。表示済みの8bit画像を平均しない。停止後の蓄積上限はUIで設定でき、0なら継続する。

画面のノイズ推定値は間接光の画素分散から算出した相対標準誤差であり、物理参照への誤差ではない。1パスでは分散を推定できないため、CSVの推定値は-1で記録する。低解像度投影や集約半径の固定バイアスは平均しても消えない。

## UIとGPUの実行

輸送ワーカーが専用のVulkan context/device/queue/command poolを持つ。ビューのコマンドプールをワーカースレッドから使わない。1パスずつ非同期に実行し、メインスレッドは完成を非ブロッキングで確認する。表示テクスチャ交換時はビュー側デバイスを待機するため、UI更新が完全に無停止とは限らない。描画フレーム間隔とフォトン画像の更新間隔を別々に測る。

## 実証の実行手順

```powershell
cmake --build Phantom/build/windows-release --target RayTracerView RayTracerTest PhotonSplatGpuTest
```

独立した作業ディレクトリ `scratch/pbvr-view-demo` にImGuiレイアウトを用意している。1280×720で、左にプレビュー、右上にOutliner、右下にCommandを配置し、他のビューを隠す。既存セッションの `imgui.ini` を変更しない。

この作業ディレクトリから、ビルドしたRayTracerViewへ `--run-scenario` と新しい `RayTracerView/scenarios/pbvr_progressive_preview.json` の絶対パスを渡す。シナリオは次を実際のビューで行う。

1. 粗いプレビューを表示して保存する。
2. 精細段階の1・4・16・32パスの画像と間接光PFMを保存する。
3. 同じ精細設定で別の乱数系列32パスを平均し、独立した有限サンプル参照を保存する。
4. 32パスのビューをスクリーンショットに保存する。
5. カメラを12度動かし、蓄積が0に戻ることを確認する。
6. 新しいカメラで4パス以上へ改善したビューを保存し、世代番号が増えたことを確認する。

出力は作業ディレクトリ内の `pbvr_preview_demo`。`passes.csv` は各パスの時間・標準誤差・深度マップ数、`frames.csv` はビュー更新間隔、`ui_timings.csv` は最初の画像と32パス到達までの時間を記録する。自動シナリオ完了時にビューは終了する。

結果を解析するには、リポジトリルートで以下を実行する。

```powershell
python Phantom/RayTracer/RayTracerView/report_pbvr_preview.py scratch/pbvr-view-demo/pbvr_preview_demo
```

解析は1・4・16・32パスの間接光と独立32パス参照の差を比較し、画像、フレーム時間、フォトン更新時間を記録する。参照は同じ近似を使う有限サンプル画像であり、従来フォトンマッピングへの一致を証明するものではない。誤差が実際に減るか、粗い初期画像がどれだけ早く出るか、UIのフレームが維持されるかを測ってから結論を出す。
